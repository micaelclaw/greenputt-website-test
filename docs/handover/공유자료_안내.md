# GreenPutt 인수인계 공유자료 안내

이 폴더는 GreenPutt 웹사이트와 Polvert 장갑 운영 자료를 인수받는 담당자가 필요한 자료를 빠르게 찾을 수 있도록 정리한 공유 폴더입니다.

## 폴더 구성

| 폴더 | 내용 |
| --- | --- |
| `00_처음_읽어주세요` | 전체 안내 문서, 인수인계서, 계정 입력 양식, 체크리스트 |
| `01_운영_증빙_서류` | 내부 담당자용 운영 증빙 자료 |
| `02_도메인_DNS_SSL_자료` | 내부 담당자용 가비아/아임웹/DNS/SSL 참고 자료 |
| `03_브랜드_로고_파비콘` | 내부 보관용 GreenPutt 로고, 파비콘 원본 및 편집 파일 |
| `04_폴베르_장갑_상품자료` | 내부 보관용 Polvert 장갑 원본 사진, 2026 신제품 사진, 작업 이미지, 로고 자료 |
| `05_소스코드_ZIP_배포자료` | 내부 담당자용 소스 ZIP과 배포 안내 문서 |
| `06_외주_담당자_전달자료` | 외주 담당자에게 공유할 소스, 배포 안내, 브랜드/Polvert 작업 자료 |

## 내부용과 외주용 구분

- `01`~`05` 폴더는 내부 담당자가 전체 자료를 보관하고 판단하기 위한 인수인계 세트입니다.
- `06_외주_담당자_전달자료` 폴더는 외주 담당자에게 전달할 파일만 선별한 세트입니다.
- 외주 담당자에게는 원칙적으로 `06` 폴더만 공유합니다. 이 폴더에는 소스 ZIP, 배포 안내, 브랜드 로고/파비콘, Polvert 상품 원본과 작업 이미지/PSD/영상 자료, 도메인/DNS 참고 캡처가 포함됩니다.

## Polvert 장갑 자료 구분

- `기존_판매제품_원본_2025까지_구형로고_포함`: 2025년까지 판매했고 현재도 판매 중인 제품 원본 자료입니다. 장갑 안쪽 또는 패치에 구형 로고가 포함된 경우가 많습니다.
- `신제품_실리콘_NEW_2026_신형로고`: 2026년 신제품 촬영 자료입니다. 장갑 안쪽 로고가 신형 로고로 되어 있는 자료입니다.
- `작업이미지_PSD_영상`: 홈페이지/상세페이지 제작 과정에서 작업한 이미지, PSD, 영상, 날짜별 작업 자료입니다.
- `폴베르_로고_신형_구형`: Polvert 구형/신형 로고 원본입니다. 상품 이미지 합성이나 상세페이지 수정 시 로고 버전을 먼저 확인합니다.

## 운영 주의사항

- 가비아/아임웹 아이디와 비밀번호는 공개 공유 폴더에 평문으로 저장하지 않습니다.
- 외주 담당자에게는 비밀번호, 계정 입력 양식, 결제 내역, 운영 증빙 원본을 기본 전달하지 않습니다.
- DNS 레코드 수정 전 현재 설정을 백업합니다.
- 메일, SPF, DKIM, DMARC, Google 인증 레코드는 삭제하지 않습니다.
