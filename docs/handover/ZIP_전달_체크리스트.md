# GreenPutt ZIP 전달 체크리스트

## 1. 소스 ZIP

- [ ] 인수인계용 소스 ZIP을 다운로드한다.
- [ ] ZIP 안에 `prototype/` 폴더가 포함되어 있는지 확인한다.
- [ ] ZIP 안에 `처음_읽어주세요.md`가 포함되어 있는지 확인한다.
- [ ] ZIP 안에 `docs/handover/` 문서가 포함되어 있는지 확인한다.
- [ ] ZIP 안에 실제 계정 비밀번호가 들어 있지 않은지 확인한다.

## 2. 공유 폴더

- [ ] `00_처음_읽어주세요` 안내문을 확인한다.
- [ ] `01_운영_증빙_서류`에 구매안전서비스 이용확인증과 통신판매업신고증이 있는지 확인한다.
- [ ] `02_도메인_DNS_SSL_자료`에 가비아/아임웹 화면 캡처가 있는지 확인한다.
- [ ] `03_브랜드_로고_파비콘`에 GreenPutt 로고와 파비콘이 있는지 확인한다.
- [ ] `04_폴베르_장갑_상품자료`에 기존 제품 원본과 2026 신제품 자료가 구분되어 있는지 확인한다.
- [ ] `05_소스코드_ZIP_배포자료`에 소스 ZIP과 배포 안내 문서가 있는지 확인한다.
- [ ] `06_외주_담당자_전달자료`에 외주 공유용 선별 자료가 있는지 확인한다.

## 3. 계정 정보

- [ ] 가비아 아이디/비밀번호 전달 방식을 확인한다.
- [ ] 아임웹 아이디/비밀번호 전달 방식을 확인한다.
- [ ] 2차 인증 또는 등록 휴대폰/이메일 정보를 확인한다.
- [ ] 비밀번호를 공개 링크 폴더에 평문으로 저장하지 않는다.

## 4. 운영 핵심 안내

- 결제/주문/회원/배송/고객센터는 아임웹이 담당한다.
- 커스텀 소스는 브랜드 홈페이지와 Polvert 구매 연결용이다.
- 배포는 Vercel을 우선 검토한다.
- GitHub Pages는 대안으로 사용할 수 있다.
- 도메인 변경 전에는 가비아 DNS를 백업한다.

## 5. 외주 전달 전 확인

- [ ] 외주 담당자에게는 `06_외주_담당자_전달자료` 폴더만 우선 공유한다.
- [ ] 가비아/아임웹 비밀번호를 외주 공유 폴더에 넣지 않는다.
- [ ] 운영 증빙 원본과 결제 내역 캡처는 기본 전달에서 제외한다.
- [ ] Polvert 작업 이미지/PSD/영상 자료가 `06` 폴더에 포함되어 있는지 확인한다.
