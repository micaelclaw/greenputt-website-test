# GreenPutt 웹사이트 인수인계 요약 문서

최종 정리일: 2026-06-10

## 1. 문서 목적

이 문서는 GreenPutt 웹사이트 인수인계 내용을 사장님 또는 의사결정자가 빠르게 이해할 수 있도록 정리한 요약본입니다.

기술적인 작업 방법보다 현재 무엇이 준비되어 있고, 어떤 결정을 해야 하며, 업체나 실무자가 어떤 일을 이어서 하면 되는지에 초점을 맞췄습니다.

## 2. 한눈에 보는 현재 상태

GreenPutt 웹사이트는 크게 두 부분으로 나뉘어 있습니다.

| 구분 | 쉽게 말하면 | 현재 역할 |
| --- | --- | --- |
| 커스텀 홈페이지 | 고객이 처음 보는 브랜드 화면 | GreenPutt 소개, 펏트너(PUTTNER) 제품 스토리, Polvert 구매 연결 |
| 아임웹 | 실제 쇼핑몰 운영 공간 | 상품 구매, 장바구니, 결제, 회원, 주문, 배송, 고객센터 |

현재 전달되는 소스는 고객에게 보여줄 GreenPutt 브랜드 홈페이지입니다. 실제 결제와 주문 관리는 기존처럼 아임웹에서 처리합니다.

## 3. 이번 인수인계에 포함된 것

- GreenPutt 홈페이지 소스 파일
- 홈페이지에 사용되는 이미지, 로고, 파비콘
- Polvert 장갑 구매 연결 구조
- 가비아 도메인/DNS 자료
- 아임웹 도메인/SSL/결제 내역 참고 자료
- 가비아와 아임웹 계정 정보를 적어둘 빈칸 양식
- 구매안전서비스 이용확인증, 통신판매업신고증
- Polvert 기존 제품 자료와 2026 신제품 촬영 자료

비밀번호는 보안상 문서와 ZIP 파일 안에 넣지 않았습니다. 가비아와 아임웹 비밀번호는 별도 방식으로 전달하는 것을 권장합니다.

## 4. 배포가 필요한 이유

현재 소스 파일은 홈페이지를 만들 수 있는 원본 자료입니다. 하지만 ZIP 파일이나 소스 파일만 가지고는 고객이 인터넷에서 접속할 수 없습니다.

고객이 `greenputt.kr` 같은 주소로 홈페이지를 보려면 소스 파일을 인터넷 서버에 올리는 과정이 필요합니다. 이 과정을 배포라고 부릅니다.

배포 후에는 보통 아래 순서로 확인합니다.

1. 임시 주소에서 홈페이지가 정상적으로 보이는지 확인합니다.
2. Polvert 구매 버튼이 아임웹 상품/장바구니로 잘 연결되는지 확인합니다.
3. 모바일과 PC 화면이 깨지지 않는지 확인합니다.
4. 문제가 없으면 `greenputt.kr` 도메인 연결 여부를 결정합니다.

즉, 배포는 홈페이지를 “파일 상태”에서 “고객이 접속할 수 있는 웹사이트 상태”로 바꾸는 단계입니다.

## 5. 배포 선택지는 이렇게 보면 됩니다

| 선택지 | 설명 | 추천 상황 |
| --- | --- | --- |
| Vercel | 홈페이지를 올리고 임시 주소로 확인하기 편한 서비스 | 우선 검토 추천 |
| GitHub Pages | Git 저장소를 이용해 정적 홈페이지를 올리는 방식 | 단순하게 운영하고 싶을 때 대안 |

사장님이 직접 기술 설정을 하실 필요는 없습니다. 업체나 담당자에게 “Vercel을 우선 검토하고, 어려우면 GitHub Pages를 대안으로 검토해 달라”고 전달하면 됩니다.

운영 도메인 `greenputt.kr`을 바로 바꾸기 전에 반드시 임시 배포 주소에서 먼저 확인하는 것이 좋습니다.

## 6. 사장님이 결정하면 좋은 것

| 결정할 항목 | 설명 |
| --- | --- |
| 새 홈페이지를 실제 운영에 반영할지 | 현재 아임웹 화면을 유지할지, 커스텀 홈페이지를 새 대표 화면으로 쓸지 결정합니다. |
| 배포 방식을 무엇으로 할지 | Vercel 우선 검토, GitHub Pages 대안 중 업체 의견을 받아 결정합니다. |
| 도메인을 언제 연결할지 | 임시 주소 검수 후 `greenputt.kr` 연결 여부를 결정합니다. |
| 계정 공유 범위 | 가비아/아임웹 계정을 누가 관리할지 정합니다. |
| Polvert 상품 정보 | 가격, 재고, 옵션, 대표 상품 URL이 맞는지 확인합니다. |
| 공유 폴더 권한 | 공개 링크로 줄지, 특정인에게만 권한을 줄지 정합니다. |

## 7. 업체 또는 실무자가 이어서 할 일

1. 소스 ZIP을 받아 압축을 풉니다.
2. 로컬 또는 임시 배포 주소에서 홈페이지를 확인합니다.
3. Polvert 구매 버튼이 아임웹으로 정상 연결되는지 확인합니다.
4. Vercel 또는 GitHub Pages 중 배포 방식을 제안합니다.
5. 임시 배포 주소를 사장님께 공유해 검수받습니다.
6. 검수 후 도메인 연결이 필요하면 가비아 DNS와 아임웹 도메인 상태를 확인합니다.
7. 도메인 변경 전 현재 DNS 설정을 백업합니다.

## 8. 도메인과 계정 정보

| 항목 | 현재 정보 |
| --- | --- |
| 대표 도메인 | `greenputt.kr` |
| 보조 도메인 | `그린펏.com` |
| 도메인 관리처 | 가비아 |
| 두 도메인 만료일 | 2035-12-19 |
| 아임웹 기본 주소 | `greenputt.imweb.me` |

가비아와 아임웹 계정 정보는 별도 입력 양식에 빈칸으로 남겨두었습니다. 비밀번호는 공개 링크 폴더나 소스 ZIP에 저장하지 않는 것이 안전합니다.

## 9. Polvert 자료 주의사항

Polvert 장갑 자료는 기존 제품과 2026 신제품이 구분되어 있습니다.

- 기존 판매 제품 자료: 2025년까지 판매했고 현재도 판매 중인 제품 자료입니다. 구형 로고가 포함된 경우가 많습니다.
- 2026 신제품 실리콘 NEW 장갑 자료: 신형 로고가 들어간 촬영본입니다.

상세페이지나 상품 이미지를 수정할 때는 구형 로고와 신형 로고를 혼동하지 않도록 먼저 확인해야 합니다.

## 10. 다음 진행 순서

1. 공유 폴더 권한을 정합니다.
2. 가비아/아임웹 계정 정보를 별도 방식으로 전달합니다.
3. 외주 담당자에게는 `06_외주_담당자_전달자료` 폴더를 우선 전달합니다.
4. 업체가 임시 배포 주소를 만들면 화면과 링크를 검수합니다.
5. 이상이 없으면 운영 도메인 연결 여부를 결정합니다.

가장 중요한 점은 운영 도메인을 바로 바꾸지 않고, 임시 배포 주소에서 먼저 확인한 뒤 연결하는 것입니다.
