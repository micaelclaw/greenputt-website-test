# GreenPutt 웹사이트 사장님용 요약 문서

최종 정리일: 2026-06-10

## 1. 이 문서는 무엇인가요?

GreenPutt 웹사이트 자료를 넘겨받을 때, 사장님이 꼭 알아야 할 내용만 쉽게 정리한 문서입니다.

전문적인 개발 용어보다 아래 세 가지를 이해하는 데 목적이 있습니다.

1. 지금 무엇이 준비되어 있는지
2. 외주 담당자에게 무엇을 맡기면 되는지
3. 사장님이 마지막에 무엇을 결정하면 되는지

## 2. 현재 준비된 화면

현재 GreenPutt 홈페이지는 아래 주소에서 참고로 열어볼 수 있습니다.

```txt
https://micaelclaw.github.io/greenputt-website-test/
```

이 주소는 최종 운영 주소가 아니라, 현재 만들어둔 홈페이지를 미리 보는 참고용 주소입니다.

나중에 실제 고객이 `greenputt.kr`로 접속하게 하려면, 외주 담당자가 화면을 다시 확인한 뒤 운영 도메인 연결을 진행하면 됩니다.

## 3. 아주 쉽게 말하면

GreenPutt 웹사이트는 두 부분으로 나뉩니다.

| 구분 | 쉽게 말하면 | 맡는 역할 |
| --- | --- | --- |
| 새 홈페이지 | 매장 앞 쇼윈도 | 브랜드 소개, 제품 소개, Polvert 구매 버튼 |
| 아임웹 | 계산대와 주문 장부 | 결제, 주문, 회원, 배송, 고객센터 |

즉, 새 홈페이지는 고객에게 보여주는 첫 화면이고, 돈을 받고 주문을 처리하는 일은 기존처럼 아임웹이 맡습니다.

## 4. 이번에 넘겨주는 자료

- 새 GreenPutt 홈페이지 소스 파일
- 홈페이지에 들어간 이미지와 로고
- Polvert 장갑 상품 자료
- 가비아 도메인 자료
- 아임웹 도메인/SSL 참고 자료
- 외주 담당자에게 바로 전달할 수 있는 `06_외주_담당자_전달자료` 폴더

가비아와 아임웹 비밀번호는 문서 안에 넣지 않았습니다. 비밀번호는 별도로 안전하게 전달하는 것이 좋습니다.

## 5. 사장님이 직접 하실 필요 없는 일

아래 일은 외주 담당자나 실무자가 처리하면 됩니다.

- 소스 파일을 여는 일
- 홈페이지를 인터넷에 올리는 일
- 모바일 화면이 깨지는지 확인하는 일
- Polvert 구매 버튼이 잘 연결되는지 확인하는 일
- 도메인 연결 전에 DNS를 백업하는 일

사장님은 결과 화면을 보고 “이대로 공개해도 되는지”만 판단하시면 됩니다.

## 6. 외주 담당자에게 맡길 일

외주 담당자에게는 전체 폴더가 아니라 먼저 아래 폴더를 공유하면 됩니다.

```txt
06_외주_담당자_전달자료
```

외주 담당자에게 요청할 말:

1. 이 폴더 안의 안내문을 먼저 확인해 주세요.
2. 홈페이지 소스 ZIP을 열어 화면을 확인해 주세요.
3. 임시 확인 주소를 만들어 주세요.
4. PC와 휴대폰에서 화면이 잘 보이는지 봐주세요.
5. Polvert 구매 버튼이 아임웹으로 잘 연결되는지 확인해 주세요.
6. 문제가 없으면 `greenputt.kr` 연결 방법을 제안해 주세요.

## 7. 사장님이 결정할 일

| 결정할 일 | 설명 |
| --- | --- |
| 새 홈페이지를 쓸지 | 현재 아임웹 화면 대신 새 홈페이지를 대표 화면으로 쓸지 결정합니다. |
| 언제 공개할지 | 임시 주소로 먼저 확인한 뒤 공개 시점을 정합니다. |
| 도메인을 연결할지 | 최종적으로 `greenputt.kr` 주소에 새 홈페이지를 연결할지 결정합니다. |
| 계정을 누가 관리할지 | 가비아와 아임웹 계정을 누가 보관하고 관리할지 정합니다. |
| 외주 공유 범위 | 외주 담당자에게는 우선 `06_외주_담당자_전달자료`만 공유합니다. |

## 9. Polvert와 제품 구성도 주의사항

Polvert 장갑 자료에는 기존 제품 자료와 2026 신제품 자료가 나뉘어 있습니다.

- 기존 제품 자료: 구형 로고가 들어간 경우가 많습니다.
- 2026 신제품 자료: 신형 로고가 들어간 자료입니다.

별도로 `그린펏_제품_구성도_참고자료` 폴더가 있습니다.

이 폴더 안의 이미지는 실제 촬영 사진이 아니라, 퍼터/매트/거리측정기 구성을 설명하기 위한 참고 이미지입니다. 날짜가 붙은 촬영 원본으로 보지 않습니다.

## 10. 가장 안전한 진행 순서

1. 외주 담당자에게 `06_외주_담당자_전달자료` 폴더를 공유합니다.
2. 외주 담당자가 임시 확인 주소를 만듭니다.
3. 사장님이 PC와 휴대폰에서 화면을 확인합니다.
4. Polvert 구매 버튼이 아임웹으로 연결되는지 확인합니다.
5. 이상이 없으면 `greenputt.kr` 연결 여부를 결정합니다.

가장 중요한 점은 바로 도메인을 바꾸지 않는 것입니다. 먼저 임시 주소에서 확인하고, 문제가 없을 때 운영 주소에 연결하는 것이 안전합니다.
