# GreenPutt 웹사이트 인수인계 요약 문서

최종 정리일: 2026-06-10

## 1. 문서 목적

이 문서는 GreenPutt 웹사이트를 인수받아 운영, 수정, 배포하는 담당자가 현재 구조와 우선 확인 항목을 빠르게 파악하기 위한 요약 문서입니다.

## 2. 핵심 요약

GreenPutt 웹사이트는 브랜드형 커스텀 홈페이지와 아임웹 커머스 운영 기능이 분리된 구조입니다.

| 구분 | 설명 |
| --- | --- |
| 커스텀 홈페이지 | 브랜드 스토리, 펏트너 제품 소개, Polvert 구매 연결 |
| 아임웹 | 상품 구매, 장바구니, 결제, 회원, 주문, 고객센터 |

## 3. 인수 범위

### 포함 항목

- 커스텀 홈페이지 소스
- 홈페이지 이미지, 로고, 파비콘
- Polvert 구매 연결 구조
- 도메인/DNS/SSL 참고 자료
- 가비아/아임웹 계정 정보 입력 양식
- 구매안전서비스 이용확인증, 통신판매업신고증 등 운영 증빙 자료
- Polvert 장갑 원본 및 2026 신제품 촬영 자료

### 제외 항목

- 별도 커스텀 결제 시스템
- 별도 주문/회원 데이터베이스
- 별도 관리자 페이지
- 후속 디자인 개편 확정안

디자인 개편은 현재 자료를 기준으로 별도 요구사항을 확인한 뒤 진행합니다.

## 4. 운영 구조

| 항목 | 현재 관리 위치 |
| --- | --- |
| 홈페이지 화면 | 전달 소스의 `prototype` 폴더 |
| Polvert 상품 구매 | 아임웹 |
| 결제/주문/배송 | 아임웹 |
| 회원/로그인 | 아임웹 |
| FAQ/공지/고객센터 | 아임웹 |
| 도메인 | 가비아, 아임웹 도메인 설정 |

## 5. 배포 방식

### Vercel 우선 검토

Vercel은 정적 사이트 배포와 미리보기 URL 확인이 편하므로 우선 검토할 배포 방식입니다. 소스 ZIP을 압축 해제한 뒤 새 Git 저장소를 만들고 Vercel에 연결합니다. 이때 `prototype` 폴더를 Root Directory로 지정합니다.

### GitHub Pages 대안

GitHub Pages도 사용할 수 있습니다. 단, 배포 브랜치와 배포 루트, 커스텀 도메인 설정을 정확히 맞춰야 합니다.

| `그린펏.com` | 가비아 | 2035-12-19 | 한글 보조 도메인 |

- 아임웹 기본 도메인: `greenputt.imweb.me`
- `greenputt.kr`은 아임웹 대표 도메인으로 선택된 상태입니다.
- `대표 도메인으로 자동연결`: ON
- `개인 도메인에 www 포함하기`: OFF
- COMODO Basic SSL 365 결제 이력이 있습니다.
- 실제 개인 도메인 SSL 적용 상태는 인수 후 다시 확인합니다.

## 8. Polvert 상품 자료 주의사항

- 2026 신제품 Polvert 실리콘 NEW 장갑 자료는 신형 로고가 들어간 촬영본입니다.
- 기존 Polvert 장갑 원본 자료는 구형 로고가 포함된 경우가 많으며, 2025년까지 판매했고 현재도 판매 중인 제품 자료입니다.
- 상세페이지나 상품 이미지를 수정할 때 신형/구형 로고를 혼동하지 않도록 확인합니다.
