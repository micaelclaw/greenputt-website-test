# GreenPutt 웹사이트 인수인계 문서

최종 정리일: 2026-06-10

## 1. 인수인계 목적

본 문서는 GreenPutt 웹사이트의 현재 상태, 운영 구조, 소스 전달 방식, 도메인/아임웹 관리 정보를 후속 업체가 이해할 수 있도록 정리한 문서입니다.

소스코드는 ZIP 형태로 전달할 수 있으며, 후속 업체는 이를 기반으로 Vercel 또는 GitHub Pages를 통해 새로 배포할 수 있습니다.

## 2. 현재 웹사이트 요약

GreenPutt 웹사이트는 퍼팅 훈련 브랜드와 펏트너(PUTTNER) 퍼팅 시스템을 소개하는 브랜드형 홈페이지입니다.

현재 사이트는 크게 두 부분으로 나뉩니다.

| 구분 | 설명 |
| --- | --- |
| 커스텀 홈페이지 | 브랜드 스토리, 제품 소개, Polvert 구매 연결 |
| 아임웹 | 상품 구매, 장바구니, 결제, 회원, 주문, 고객센터 |

## 3. 인수 범위

### 포함되는 항목

- 커스텀 홈페이지 소스
- 홈페이지 이미지/로고/파비콘
- Polvert 구매 연결 구조
- 도메인/DNS/SSL 참고 자료
- 가비아/아임웹 계정 정보 입력 양식
- 구매안전서비스 이용확인증, 통신판매업신고증 등 운영 증빙 자료
- Polvert 장갑 원본 및 2026 신제품 촬영 자료

### 포함되지 않는 항목

- 별도 커스텀 결제 시스템
- 별도 주문/회원 데이터베이스
- 별도 관리자 페이지
- 후속 디자인 개편 확정안

후속 디자인 개편은 사장님 지시에 따라 별도 진행하면 됩니다.

## 4. 운영 구조

| 항목 | 현재 관리 위치 |
| --- | --- |
| 홈페이지 화면 | 전달 소스의 `prototype` 폴더 |
| Polvert 상품 구매 | 아임웹 |
| 결제/주문/배송 | 아임웹 |
| 회원/로그인 | 아임웹 |
| FAQ/공지/고객센터 | 아임웹 |
| 도메인 | 가비아, 아임웹 도메인 설정 |

## 5. 배포 제안

### 추천: Vercel

Vercel을 우선 권장합니다.

후속 업체가 소스 ZIP을 압축 해제한 뒤 새 Git 저장소를 만들고, Vercel에 연결하면 정적 사이트로 배포할 수 있습니다. 이때 `prototype` 폴더를 Root Directory로 지정하는 방식을 권장합니다.

### 대안: GitHub Pages

GitHub Pages도 가능합니다. 다만 배포 브랜치와 배포 루트, 커스텀 도메인 설정을 정확히 맞춰야 합니다.

## 6. 도메인 및 SSL 정보

| 도메인 | 관리처 | 만료일 | 비고 |
| --- | --- | --- | --- |
| `greenputt.kr` | 가비아 | 2035-12-19 | 대표 운영 도메인 |
| `그린펏.com` | 가비아 | 2035-12-19 | 한글 보조 도메인 |

아임웹 기본 도메인은 `greenputt.imweb.me`입니다.

아임웹 도메인 화면 기준으로 `greenputt.kr`이 대표 도메인으로 선택되어 있고, `대표 도메인으로 자동연결`은 ON, `개인 도메인에 www 포함하기`는 OFF입니다.

COMODO Basic SSL 365 결제 이력이 있으나, 실제 개인 도메인 SSL 적용 상태는 후속 업체가 인수 후 다시 확인해야 합니다.

## 8. Polvert 상품 자료 주의사항

- 2026 신제품 Polvert 실리콘 NEW 장갑 자료는 신형 로고가 들어간 촬영본입니다.
- 기존 Polvert 장갑 원본 자료는 구형 로고가 포함된 경우가 많으며, 2025년까지 판매했고 현재도 판매 중인 제품 자료입니다.
- 상세페이지나 상품 이미지를 수정할 때 신형/구형 로고를 혼동하지 않도록 확인해야 합니다.

## 9. 인수 후 우선 확인할 일

1. 소스 ZIP 압축 해제 및 로컬 실행
2. Vercel 또는 GitHub Pages 배포 방식 결정
3. 임시 배포 URL에서 화면/링크 테스트
4. 아임웹 상품/주문/고객센터 접근 확인
5. 가비아 DNS 백업
6. SSL 적용 상태 확인
7. 운영 도메인 연결 여부 결정
