## 2. 이메일 / 공식 전달용 버전

제목: GreenPutt 웹사이트 인수인계 자료 공유드립니다

안녕하세요.

GreenPutt 웹사이트 인수인계 자료를 공유드립니다.

공유 폴더에는 현재 홈페이지 소스, 운영 증빙 서류, 도메인/DNS/SSL 참고 자료, GreenPutt 로고/파비콘, Polvert 장갑 상품 자료가 정리되어 있습니다.

먼저 아래 폴더와 문서를 순서대로 확인 부탁드립니다.

1. `00_처음_읽어주세요/01_자료_구성_안내.md`
2. `00_처음_읽어주세요/02_소스_먼저_읽어주세요.md`
3. `00_처음_읽어주세요/03_그린펏_웹사이트_실무용_인수인계서.md`
4. `05_소스코드_ZIP_배포자료/01_소스코드_ZIP_전달_및_배포_안내.md`

현재 GreenPutt 웹사이트는 커스텀 정적 홈페이지와 아임웹 운영 기능이 나뉘어 있습니다.

- 커스텀 홈페이지 소스는 브랜드 소개, 펏트너(PUTTNER) 제품 스토리, Polvert 구매 연결 역할을 합니다.
- 결제, 주문, 회원, 배송, 취소/환불, 고객센터는 아임웹에서 운영합니다.
- 후속 배포는 Vercel을 우선 권장하며, GitHub Pages도 대안으로 가능합니다.

도메인 관련해서는 `greenputt.kr`, `그린펏.com` 모두 가비아에서 관리 중이며 만료일은 2035-12-19입니다. DNS 또는 대표 도메인을 변경하기 전에는 반드시 현재 가비아 DNS 설정을 백업해 주세요.

Polvert 장갑 자료는 기존 판매 제품과 2026 신제품 자료를 분리해두었습니다.

- 기존 판매 제품: 2025년까지 판매했고 현재도 판매 중인 제품 자료이며, 구형 로고가 포함된 경우가 많습니다.
- 2026 신제품: 실리콘 NEW 장갑 촬영본이며, 장갑 안쪽 로고가 신형 로고로 되어 있습니다.

가비아와 아임웹 계정 정보는 보안상 공유 폴더에 비밀번호를 넣지 않고 별도 방식으로 전달드리겠습니다.

확인 후 필요한 접근 권한이나 추가 자료가 있으면 말씀 부탁드립니다.

감사합니다.

## 3. 업체에게 같이 전달할 핵심 주의사항

- 소스 ZIP 안에 실제 비밀번호는 없습니다.
- 계정 정보는 별도 전달 예정입니다.
- 운영 도메인 연결 전에는 임시 배포 URL에서 화면과 링크를 먼저 확인해야 합니다.
- DNS 수정 전 가비아 설정을 백업해야 합니다.
- 메일, SPF, DKIM, DMARC, Google 인증 레코드는 삭제하면 안 됩니다.
- Polvert 상품 이미지 수정 시 신형/구형 로고를 구분해야 합니다.
