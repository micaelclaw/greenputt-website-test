# GreenPutt ZIP 전달 체크리스트

## 1. 소스 ZIP

- [ ] GitHub에서 인수인계용 브랜치 ZIP을 다운로드한다.
- [ ] ZIP 안에 `prototype/` 폴더가 포함되어 있는지 확인한다.
- [ ] ZIP 안에 `READ_ME_FIRST.md`가 포함되어 있는지 확인한다.
- [ ] ZIP 안에 `docs/handover/` 문서가 포함되어 있는지 확인한다.
- [ ] ZIP 안에 실제 계정 비밀번호가 들어 있지 않은지 확인한다.

## 2. 공유 폴더

- [ ] `00_처음_읽어주세요` 안내문을 확인한다.
- [ ] `01_운영_증빙_서류`에 구매안전서비스 이용확인증과 통신판매업신고증이 있는지 확인한다.
- [ ] `02_도메인_DNS_SSL_자료`에 가비아/아임웹 화면 캡처가 있는지 확인한다.
- [ ] `03_브랜드_로고_파비콘`에 GreenPutt 로고와 파비콘이 있는지 확인한다.
- [ ] `04_폴베르_장갑_상품자료`에 기존 제품 원본과 2026 신제품 자료가 구분되어 있는지 확인한다.
- [ ] `05_소스코드_ZIP_배포자료`에 소스 ZIP을 넣는다.

## 3. 계정 정보

- [ ] 가비아 아이디/비밀번호 전달 방식을 정한다.
- [ ] 아임웹 아이디/비밀번호 전달 방식을 정한다.
- [ ] 2차 인증 또는 등록 휴대폰/이메일 정보를 확인한다.
- [ ] 비밀번호를 공개 링크 폴더에 평문으로 두지 않는다.

## 4. 후속 업체에게 전달할 핵심 안내

- 결제/주문/회원/배송/고객센터는 아임웹이 담당한다.
- 커스텀 소스는 브랜드 홈페이지와 Polvert 구매 연결용이다.
- 배포는 Vercel을 우선 권장한다.
- GitHub Pages는 대안으로 가능하다.
- 도메인 변경 전에는 반드시 가비아 DNS를 백업한다.
