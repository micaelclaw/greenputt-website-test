# 그린펏 인수인계 공유자료 안내

이 폴더는 GreenPutt 웹사이트와 Polvert 장갑 운영 인수인계를 위해 따로 정리한 공유용 자료 폴더입니다.

## 폴더 구성

| 폴더 | 내용 |
| --- | --- |
| `01_운영_증빙_서류` | 구매안전서비스 이용확인증, 통신판매업신고증 등 운영 증빙 자료 |
| `02_도메인_DNS_SSL_자료` | 가비아 DNS, 아임웹 도메인 설정, SSL/결제 내역 화면 캡처 |
| `03_브랜드_로고_파비콘` | GreenPutt 로고, 파비콘 원본 및 편집 파일 |
| `04_폴베르_장갑_상품자료` | Polvert 장갑 원본 사진, 2026 신제품 사진, 작업 이미지, 로고 자료 |
| `05_소스코드_ZIP_배포자료` | Git에서 다운로드한 소스 ZIP과 배포 안내 문서 |

## Polvert 장갑 자료 구분

- `기존_판매제품_원본_2025까지_구형로고_포함`: 2025년까지 판매했고 현재도 판매 중인 제품 원본 자료입니다. 장갑 안쪽 또는 패치에 구형 로고가 포함된 경우가 많습니다.
- `신제품_실리콘_NEW_2026_신형로고`: 2026년 신제품 촬영 자료입니다. 장갑 안쪽 로고가 신형 로고로 되어 있는 자료입니다.
- `작업이미지_PSD_영상`: 홈페이지/상세페이지 제작 과정에서 작업한 이미지, PSD, 영상, 날짜별 작업 자료입니다.
- `폴베르_로고_신형_구형`: Polvert 구형/신형 로고 원본입니다. 상품 이미지 합성이나 상세페이지 수정 시 로고 버전을 먼저 확인해야 합니다.

## 도메인 참고

- `greenputt.kr` 만료일: 2035-12-19
- `그린펏.com` 만료일: 2035-12-19
- 현재 도메인/DNS/SSL 상태는 `02_도메인_DNS_SSL_자료`의 화면 캡처와 인수인계 문서를 함께 확인해야 합니다.

## 공유 전 주의사항

- 이 폴더는 외부 업체 공유를 전제로 정리한 자료입니다.
- 가비아/아임웹 아이디와 비밀번호는 이 폴더에 직접 저장하지 말고, 별도 보안 채널로 전달하는 것을 권장합니다.
- DNS 레코드 수정 전에는 반드시 현재 설정을 백업하고, 메일/SPF/DKIM/DMARC/Google 인증 레코드를 삭제하지 않도록 확인해야 합니다.
