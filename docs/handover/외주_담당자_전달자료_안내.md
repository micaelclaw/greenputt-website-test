# GreenPutt 외주 담당자 전달자료 안내

최종 정리일: 2026-06-10

## 1. 문서 목적

이 문서는 외주 개발자 또는 웹사이트 담당자에게 전달할 자료만 따로 모아둔 안내입니다.

내부 운영 증빙, 계정 정보, 결제 내역, 전체 작업 원본처럼 외주 작업에 바로 필요하지 않거나 민감할 수 있는 자료는 기본 전달 범위에서 제외합니다.

## 2. 외주 담당자에게 전달할 기본 자료

| 폴더 | 내용 |
| --- | --- |
| `00_먼저_읽어주세요` | 작업 범위, 배포 안내, 아임웹 연동 방식, 도메인 참고 문서 |
| `01_소스코드_ZIP` | GreenPutt 홈페이지 소스 ZIP |
| `02_브랜드_로고_파비콘` | GreenPutt 로고와 파비콘 |

| `04_도메인_DNS_참고자료` | 가비아 DNS와 아임웹 도메인 연결 상태 캡처 |

## 3. 외주 담당자 작업 범위

외주 담당자는 아래 범위를 기준으로 작업합니다.

1. 소스 ZIP을 압축 해제하고 홈페이지가 정상 실행되는지 확인합니다.
2. Vercel을 우선 검토하고, 필요하면 GitHub Pages를 대안으로 검토합니다.
3. 임시 배포 주소에서 화면, 모바일 반응형, 이미지 표시 상태를 확인합니다.
4. Polvert 구매 버튼이 아임웹 상품 또는 장바구니 URL로 정상 연결되는지 확인합니다.
5. 임시 배포 주소를 공유해 내부 검수를 받습니다.
6. 운영 도메인 연결이 필요하면 가비아 DNS와 아임웹 도메인 상태를 변경 전 백업합니다.

## 4. 외주 담당자에게 전달하지 않는 기본 자료

아래 자료는 내부 담당자 확인용입니다. 외주 담당자가 꼭 필요하다고 요청할 때만 별도로 선별해 공유합니다.

- 가비아/아임웹 아이디와 비밀번호
- 계정 정보 입력 양식
- 구매안전서비스 이용확인증, 통신판매업신고증 원본
- 아임웹 결제 내역 캡처
- 가격표, 공급가 등 외부 공개가 민감할 수 있는 자료

## 5. 배포 관련 설명

소스 ZIP은 홈페이지 원본 파일입니다. 고객이 인터넷에서 접속하려면 이 파일을 Vercel 또는 GitHub Pages 같은 정적 호스팅 서비스에 올려야 합니다.

권장 순서:

1. 임시 배포 주소를 먼저 만듭니다.
2. 화면과 링크를 내부에서 검수합니다.
3. 문제가 없을 때만 `greenputt.kr` 도메인 연결 여부를 결정합니다.

운영 도메인을 바로 바꾸지 않고 임시 주소에서 먼저 확인하는 것이 안전합니다.

## 6. Polvert 자료 사용 주의사항

- `기존 판매제품 원본` 자료는 2025년까지 판매했고 현재도 판매 중인 제품입니다. 구형 로고가 포함된 경우가 많습니다.
- `2026 신제품 실리콘 NEW 장갑` 자료는 신형 로고가 들어간 촬영본입니다.
- 상품 이미지나 상세페이지를 수정할 때는 신형/구형 로고를 혼동하지 않도록 확인합니다.
- 외주 전달 세트에는 작업 이미지, PSD, 영상 자료도 포함되어 있습니다. 용량이 크므로 다운로드와 동기화 시간을 감안합니다.

## 7. 외주 담당자 확인 체크리스트

- [ ] 소스 ZIP 압축 해제 확인
- [ ] 로컬 또는 임시 주소에서 홈페이지 화면 확인
- [ ] 모바일/데스크톱 화면 확인
- [ ] Polvert 구매 버튼 링크 확인
- [ ] 아임웹 결제/주문/회원 기능은 별도 개발하지 않는다는 점 확인
- [ ] 도메인 변경 전 DNS 백업 필요 여부 확인
- [ ] 계정 비밀번호를 외주 공유 폴더에 저장하지 않았는지 확인
