# GreenPutt 웹사이트 내부 담당자용 요약 문서

최종 정리일: 2026-06-10

## 1. 문서 목적

이 문서는 GreenPutt 웹사이트를 내부 담당자가 넘겨받아 외주 담당자와 소통하고, 배포/도메인/자료 관리를 판단할 수 있도록 정리한 요약 문서입니다.

사장님용 요약 문서보다 조금 더 실무적인 내용이 포함되어 있지만, 실제 개발 작업 절차보다는 인수 후 관리와 의사결정에 초점을 둡니다.

## 2. 핵심 요약

GreenPutt 웹사이트는 커스텀 홈페이지와 아임웹 운영 기능이 분리된 구조입니다.

| 구분 | 설명 |
| --- | --- |
| 커스텀 홈페이지 | GreenPutt 브랜드 소개, 펏트너(PUTTNER) 제품 스토리, Polvert 구매 연결 |
| 아임웹 | 상품 구매, 장바구니, 결제, 회원, 주문, 배송, 고객센터 |
| 도메인/DNS | 가비아와 아임웹 도메인 설정에서 관리 |
| 외주 전달 자료 | `06_외주_담당자_전달자료` 폴더에 별도 구성 |

현재 참고용 GitHub Pages 주소:

```txt
https://micaelclaw.github.io/greenputt-website-test/
```

이 주소는 최종 운영 주소가 아니라 현재 화면을 확인하기 위한 참고 배포 주소입니다.

## 3. 인수 범위

### 포함 항목

- 커스텀 홈페이지 소스 ZIP
- 홈페이지 이미지, 로고, 파비콘
- Polvert 구매 연결 구조
- 가비아 DNS 캡처와 도메인 참고 자료
- 아임웹 도메인/SSL 참고 자료
- 가비아/아임웹 계정 정보 입력 양식
- 구매안전서비스 이용확인증, 통신판매업신고증
- Polvert 기존 제품 자료, 2026 신제품 자료, 작업 이미지/PSD/영상
- 외주 담당자에게 전달할 별도 `06` 폴더

### 제외 또는 별도 관리 항목

- 실제 가비아/아임웹 비밀번호
- 별도 커스텀 결제 시스템
- 별도 주문/회원 데이터베이스
- 별도 관리자 페이지
- 후속 디자인 개편 확정안

비밀번호는 공유 폴더나 소스 ZIP에 평문으로 저장하지 않고 별도 방식으로 전달합니다.

## 4. 운영 구조

| 항목 | 현재 관리 위치 |
| --- | --- |
| 홈페이지 화면 | 전달 소스의 `prototype` 폴더 |
| Polvert 상품 구매 | 아임웹 |
| 결제/주문/배송 | 아임웹 |
| 회원/로그인 | 아임웹 |
| FAQ/공지/고객센터 | 아임웹 |
| 도메인 | 가비아, 아임웹 도메인 설정 |
| 외주 작업용 자료 | 공유 폴더의 `06_외주_담당자_전달자료` |

커스텀 홈페이지는 고객에게 보여주는 브랜드 화면이고, 실제 커머스 운영은 아임웹이 담당합니다.

## 5. 배포 판단 기준

배포는 홈페이지 소스 파일을 고객이 인터넷에서 접속할 수 있는 상태로 올리는 과정입니다.

| 방식 | 설명 | 내부 판단 기준 |
| --- | --- | --- |
| Vercel | 정적 홈페이지 배포와 임시 URL 확인이 편한 방식 | 우선 검토 |
| GitHub Pages | Git 저장소를 이용한 정적 홈페이지 배포 방식 | 대안으로 검토 |

운영 도메인 `greenputt.kr`을 바로 변경하지 말고, 먼저 임시 배포 주소에서 화면과 링크를 확인합니다.

확인할 항목:

1. 첫 화면이 정상 표시되는지
2. 모바일과 데스크톱 레이아웃이 깨지지 않는지
3. Polvert 구매 버튼이 아임웹 상품 또는 장바구니로 연결되는지
4. 아임웹의 결제/주문/회원/고객센터 역할이 유지되는지
5. 도메인 변경 전 DNS 백업이 준비되었는지

메일, SPF, DKIM, DMARC, Google 인증 레코드는 삭제하지 않습니다.

## 7. 계정 정보 관리

계정 정보는 `계정정보_입력양식.md`에 빈칸으로만 준비되어 있습니다.

| 계정 | 관리 위치 | 전달 방식 |
| --- | --- | --- |
| 가비아 | 도메인/DNS 관리 | 별도 보안 채널 권장 |

## 9. Polvert 및 제품 자료 주의사항

- 기존 Polvert 제품 자료는 구형 로고가 포함된 경우가 많습니다.
- 2026 신제품 실리콘 NEW 장갑 자료는 신형 로고가 들어간 자료입니다.
- `그린펏_제품_구성도_참고자료`는 실제 촬영 사진이 아니라 퍼터, 매트, 거리측정기 구성을 설명하기 위한 참고 이미지입니다.
- 상세페이지나 상품 이미지를 수정할 때는 신형/구형 로고를 혼동하지 않도록 확인합니다.
- 가격, 재고, 옵션은 실제 판매 전 아임웹 상품 설정에서 다시 확인합니다.
