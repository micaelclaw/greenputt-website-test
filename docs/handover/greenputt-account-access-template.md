| 항목 | 내용 |
| --- | --- |
| SSL 결제 이력 | COMODO Basic SSL 365 |

| SSL 적용 상태 | 아임웹 도메인 화면에서 개인 도메인 SSL 적용 상태 재확인 필요 |

## 4. DNS 수정 전 확인

- DNS 레코드를 수정하기 전 가비아에서 현재 DNS 레코드를 백업합니다.
- 메일, SPF, DKIM, DMARC, Google 인증 레코드는 삭제하지 않습니다.
- `greenputt.kr`과 `그린펏.com`의 네임서버, 대표 도메인, SSL 상태를 함께 확인합니다.
