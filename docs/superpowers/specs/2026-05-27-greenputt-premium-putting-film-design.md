# GreenPutt Premium Putting Film Design

Date: 2026-05-27
Status: Approved for prototype implementation

## Direction

The next GreenPutt homepage prototype should move away from abstract UI graphics and use actual GreenPutt/Polvert visual assets. The target is `Premium Putting Film`: a campaign-led page that feels credible like Titleist, product-immersive like Crossputt, and specific to GreenPutt's Zero Head-Up system.

## Design Thesis

- Titleist influence: large photographic campaign impression, calm navigation, confident whitespace, and clear product pathways.
- Crossputt influence: putting close-ups, product-first storytelling, darker cinematic image treatment, and focused technical narrative.
- GreenPutt identity: Zero Head-Up, distance feedback near the ball, putting mat/device system, and Polvert as a separate `GreenPutt StorePick`.

## Page Shape

1. Hero film frame
   - Use a real GreenPutt system render as the dominant image.
   - Keep `Heads Down. Data On.` as the main line.
   - First viewport should feel like a premium golf campaign, not a dashboard.

2. Zero Head-Up story
   - Explain the head-up problem with a close product/use image and short copy.
   - Emphasize that the golfer checks distance feedback without lifting the head.

3. Product system
   - Present putter assistant, mat, range feedback device, and Polvert as one GreenPutt ecosystem.
   - Use visual hierarchy and product states instead of generic cards.

4. GreenPutt StorePick
   - Use Polvert real product imagery.
   - Keep purchase links provisional; design comes first.
   - Make it visually premium but secondary to GreenPutt's own putting system.

5. Bridge and support
   - Keep commerce/member/order/support boundaries in Imweb.
   - Links can be finalized later.

## Success Criteria

- The page immediately reads as a golf/putting brand with a real product.
- It no longer feels like an abstract generated SaaS-style page.
- The first viewport has a Titleist-level campaign scale.
- The middle sections have Crossputt-style product focus.
- Polvert is clearly a store pick, not the main GreenPutt invention.
- The prototype remains static, maintainable, and easy to export into Imweb content later.
